How the radar scores

Implied value = TVL × 0.25 × growth × maturity × breadth. Growth is the 7-day TVL change clamped to −60…+120% at half weight; maturity rises with how long the protocol has run with no token (0.60 → 1.00 over 3 years, 365 days when its start date is unknown); breadth is 1 + 0.05 × ln(chains). The same function scores every row — no name is ever special-cased. Change the constants in the Model sandbox and the board re-ranks live.

What counts as pre-token: the protocol's record carries no token (no market cap, no CoinGecko id, no symbol) and it is not a wrapped, staked or bridged product of a token that already trades — the watchlist's own exclusion rule, applied to the whole board. That is why WBTC, Binance staked ETH and USDT0 never appear here: their tokens already trade, so they are not launches to farm. “Records no token” is not proof a protocol has none, only what its record says.

Read the board: rank 1 is the most valuable launch on the model. Every row carries a six-step farm plan with what it costs and how long it takes, derived from the protocol's category, chains, TVL and age. The Live tokens tab shows protocols whose token already trades at the market's own value, kept apart from the ranked board. Implied value is this entry's own claim, never a promise a token launches or what it will be worth.
